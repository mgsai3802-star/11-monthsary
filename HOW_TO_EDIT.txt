ပုံထည့်နည်း
==========

1. ကိုယ်သုံးချင်တဲ့ပုံ ၆ ပုံကို JPG အဖြစ်ထားပါ။
2. ဒီ images folder ထဲကို အောက်ပါအမည်တွေနဲ့ထည့်ပါ။
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
   photo5.jpg
   photo6.jpg
3. index.html နဲ့ images folder ကို GitHub repository တစ်ခုတည်းထဲ upload လုပ်ပါ။

PNG သုံးချင်ရင် index.html ထဲက const CONFIG > photos မှာ .jpg ကို .png ပြောင်းပါ။

စာပြင်နည်း
==========
index.html ကို text editor နဲ့ဖွင့်ပြီး “const CONFIG” လို့ရှာပါ။
partnerName, relationshipStart, letter, quiz, timeline, reasons တို့ကို အဲဒီနေရာမှာပြင်နိုင်ပါတယ်။

သတိပြုရန်
==========
Website ထဲက Choose Photos က preview သာဖြစ်ပြီး refresh လုပ်ရင် ပျောက်ပါမယ်။
GitHub ပေါ်မှာ အမြဲပြစေချင်ရင် images folder ထဲကို ပုံဖိုင်တွေကို တကယ် upload လုပ်ရပါမယ်။
